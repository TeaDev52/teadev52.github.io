О программе

NoBan — сетевой инструмент для Windows, предназначенный для восстановления доступа к сайтам и сервисам, ограниченным сетевой фильтрацией. В основе проекта используются DPI-обход, наборы правил, профили запуска и сетевой драйвер WinDivert.

Программа включает ручной запуск профилей, управление запуском вместе с Windows, диагностику состояния компонентов, переключение сетевых фильтров и дополнительные инструменты для работы с системным файлом hosts.

Важно Результат зависит от провайдера, сети, версии Windows и выбранного профиля. Универсально подходящего профиля для всех подключений нет.

Описание файлов

Что находится в папке NoBan v8.1 и за что отвечает каждый компонент.

▰ Корневая папка
NoBan.bat
Главный лаунчер

Открывает меню ручного запуска и позволяет выбрать один из 18 профилей — от A до R. Перед запуском запрашивает права администратора, проверяет флаг игрового фильтра и запускает NoBan.exe с параметрами выбранного профиля.

service.bat
Панель управления NoBan

Управляет службой Windows, проверяет состояние компонентов, запускает диагностику, переключает параметры фильтрации, работает со списками и проверяет обновления.

▰ bin\ — исполняемые компоненты
NoBan.exe
Основной сетевой компонент

Исполняемый файл, который запускается выбранным профилем и выполняет сетевую обработку.

WinDivert.dll WinDivert64.sys
Компоненты WinDivert

Библиотека и драйвер, необходимые для перехвата и обработки сетевого трафика.

curl.exe
Загрузка файлов

Используется служебными сценариями для получения данных и обновления списков с GitHub.

cygwin1.dll
Вспомогательная библиотека

Сопутствующая библиотека, находящаяся рядом с исполняемыми компонентами.

*.bin
Шаблоны пакетов

Бинарные шаблоны, используемые профилями NoBan при обработке сетевых соединений. В сборке присутствуют, например, quic_initial_www_google_com.bin и TLS ClientHello-шаблоны.

game_filter.enabled
Флаг игрового фильтра

Наличие файла означает, что расширенный игровой фильтр включён. При его отсутствии используется стандартный набор портов.

update_check.disabled
Флаг проверки обновлений

Наличие файла отключает автоматическую проверку обновлений в служебном меню.

▰ lists\ — списки и правила
white-list.txt
Белый список доменов

Домены, для которых применяются правила обхода.

black-list.txt
Чёрный список доменов

Домены, которые исключаются из обработки по правилам проекта.

ipset-all.txt
Список IP-адресов

Используется в режиме loaded для работы IP-фильтра.

ipset-exclude.txt
Исключения IP

Список адресов, которые нужно исключать из соответствующей обработки.

hosts-*.txt
Готовые записи hosts

Файлы для Spotify, Telegram, IntelliJ и Roblox. Применяются отдельной функцией из service.bat.

▰ autoload\ — профили автозапуска
*.bat
Файлы автозагрузки

Профили запуска, подготовленные для установки NoBan в автозагрузку Windows. При настройке службы пользователь выбирает подходящий файл, а панель управления использует его параметры для запуска.

Состав описан по предоставленной сборке NoBan v8.1. Если в следующих версиях появятся новые папки или компоненты, документация будет обновлена.

Функции service.bat

Панель управления запускается с правами администратора. В меню доступны следующие действия:

01
Проверить статус

Показывает состояние службы NoBan и WinDivert, а также проверяет, запущена ли служба.

02
Выполнить диагностику

Проверяет систему на известные конфликты и компоненты, которые могут мешать работе NoBan.

03
Проверка обновлений

Включает или отключает автоматическую проверку. При обнаружении новой версии открывается страница последнего релиза.

04
Игровой фильтр

Переключает расширенный диапазон портов TCP/UDP 1024–65535. После изменения параметра требуется перезапустить NoBan.

05
Переключение IPSet

Переключает режимы loaded — использовать ipset-all.txt, none — не применять IP-список, any — режим без ограничения этим списком.

06
Установить автозагрузку

Создаёт службу Windows на основе выбранного профиля из папки autoload, чтобы NoBan запускался вместе с системой.

07
Убрать автозагрузку / Остановить NoBan

Останавливает и удаляет службу NoBan, а также завершает работу связанных компонентов.

08
Разблокировка через Hosts

Добавляет подготовленные записи для Spotify, Telegram, IntelliJ или Roblox в системный файл hosts и сбрасывает DNS-кэш.

09
Сбросить списки

Загружает оригинальные версии white-list.txt, black-list.txt, ipset-all.txt и ipset-exclude.txt из репозитория.

10
Добавление доменов

Добавление доменов — функция для быстрого добавления доменов популярных платформ в white-list.txt или black-list.txt.

▶

Функции NoBan.bat

Главный лаунчер предназначен для ручного запуска. В меню можно выбрать профиль от A до R — цифрой или буквой. Скрипт проверяет состояние игрового фильтра и запускает соответствующий профиль через NoBan.exe.

Обрати внимание Если NoBan уже работает как служба Windows, повторно запускать профиль вручную не требуется.

!

Важные примечания

Права администратора. Для установки службы и изменения системных параметров запускай NoBan.bat и service.bat от имени администратора.

Антивирусы. Защитное ПО может предупреждать о WinDivert и сетевых компонентах, поскольку они работают с трафиком. Не отключай защиту вслепую: проверяй источник файлов и содержимое релиза.

Easy Anti-Cheat. Из-за античита Easy Anti-Cheat в некоторых играх, например Fortnite и Rust, NoBan может работать хуже или конфликтовать с сетевыми функциями игры.

Кодировка. Для корректного отображения кириллицы в консоли BAT-файлы используют UTF-8 и настройку кодовой страницы.

Источник загрузки. Используй только официальный репозиторий github.com/voanechay42/NoBan ↗.
