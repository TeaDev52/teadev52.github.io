NoBan — проект, объединяющий необходимые компоненты и настройки для работы с сетевым подключением. Цель страницы — дать пользователю понятную информацию о проекте, его составе, версиях и известных особенностях.

Сервис и компоненты

Основная часть проекта и вспомогательные системные компоненты, необходимые для его работы.

Сетевой компонент

В проекте используется WinDivert — инструмент перехвата и фильтрации сетевого трафика. Его наличие может вызывать предупреждения защитного ПО.

В README репозитория собраны актуальные примечания, требования и пояснения автора.

!

Предупреждение антивируса

Некоторые защитные программы могут реагировать на WinDivert или связанные с ним системные файлы. Само по себе такое предупреждение не доказывает ни безопасность, ни вредоносность файла. Скачивай сборки только из официального репозитория NoBan и проверяй опубликованные контрольные суммы, если они доступны.
