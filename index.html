NoBan

Основные функции и API для работы с вашим проектом.

NoBan — это библиотека для основных хуков и механизмов совместимости. Примеры включают:

  • Предоставление функционала, который сложно получить другими способами.
  • Добавление событий, хуков и API для улучшения совместимости между модами.
  • Продвинутый API рендеринга, разработанный для совместимости с модами на оптимизацию.

Использование NoBan

Убедитесь, что вы установили Fabric Loader. Подробную информацию о том, как установить загрузчик, можно найти здесь.

Скачанный файл `.jar` необходимо поместить в папку mods.
